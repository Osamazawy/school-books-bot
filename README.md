# 📚 بوت تيليجرام لإدارة وتوزيع الكتب والمناهج الدراسية (PDF)

مشروع محترف ومتكامل لبوت تيليجرام مخصص لإدارة وتوزيع الكتب والمناهج الدراسية بصيغة PDF عبر قاعدة بيانات SQLite ومكتبة `python-telegram-bot` الإيراد الأحدث التزامني (Async v20+).

---

## 🌟 ميزات المشروع

- **تصفح ديناميكي وتفاعلي**: التنقل السلس بين المراحل الدراسية -> المواد -> الكتب عبر أزرار الـ Inline Keyboard.
- **إرسال الملفات بدون إعادة رفع**: يعتمد البوت على حفظ معرّف الملف `telegram_file_id` وإرساله للمستخدم مباشرة وبسرعة فائقة.
- **بحث محرك داخل البوت**: إمكانية البحث عن الكتاب فورياً برقم أو عنوان الكتاب أو اسم المادة.
- **لوحة تحكم كاملة للمشرفين (Admin Panel)**:
  - إضافة مراحل دراسية ومواد جديدة.
  - إضافة كتب جديدة برفع الملف المستند مباشرة واستخراج الـ `file_id` آلياً.
  - حذف وتعديل بيانات الكتب.
  - استخراج إحصائيات النظام (عدد المستخدمين، المراحل، المواد، والكتب).
- **قواعد البيانات والحماية**: قاعدة بيانات SQLite منفصلة بعلاقات Foreign Keys وقيود أمان.
- **دعم تسجيل السجلات (Logging)** و معالجة الأخطاء الاحترافية.

## ⚙️ متطلبات التشغيل (Requirements)

- Python 3.9 أو أعلى.
- توكن بوت من `@BotFather`.
- معرّف الآدمن الخاص بك من `@userinfobot`.

---

## 🚀 طريقة التشغيل خطوة بخطوة

### 1️⃣ استคลاخ المشروع وتثبيت المكتبات
قم بفتح أداة موجه الأوامر (Terminal / Command Prompt) في مجلد المشروع وقم بتثبيت حزم بايثون:

```bash
pip install -r requirements.txt
```

### 2️⃣ ضبط الإعدادات `config.py`
افتح ملف `config.py` واستبدل البيانات التالية:
- ضع التوكن الخاص بك مكان `YOUR_BOT_TOKEN_HERE`.
- ضع معرّف الحساب (ID) الخاص بك في قائمة `ADMIN_IDS` (مثال: `[123456789]`).

أو قم بتعيين متغيرات البيئة بالشكل التالي:

```bash
export BOT_TOKEN="123456789:ABCdefGhIJKlmNoPQRstuVWXyz"
export ADMIN_IDS="123456789,987654321"
```

### 3️⃣ (اختياري) إضافة بيانات تجريبية أولية
يمكنك تشغيل السكربت التالي لإنشاء المراحل والمواد الأولى تلقائياً:

```bash
python seed_example_data.py
```

### 4️⃣ تشغيل البوت
قم بتشغيل الملف الرئيسي:

```bash
python main.py
```

## 🛠️ أوامر واستخدام لوحة التحكم (Admins)

1. أرسل الأمر `/start` للبدء كـ مستخدم.
2. أرسل الأمر `/admin` لفتح لوحة التحكم (تظهر فقط للحسابات المضافة في `ADMIN_IDS`).
3. **لإضافة كتاب جديد**:
   - اضغط على `➕ إضافة كتاب جديد`.
   - اختر المرحلة ثم المادة.
   - ادخل عنوان الكتاب والوصف.
   - قم **برفع وأرسال ملف PDF الكتاب** للمحادثة.
   - سيقوم البوت باستخراج الـ `file_id` وحفظه في قاعدة البيانات فوراً.

---

## 🔒 أمان واستقرار النظام

- يتم التأكد من كل طلب مشرف عبر فلتر `IS_ADMIN`.
- يتم استخدام `PRAGMA foreign_keys = ON` لضمان صحة العلاقات واتساق البيانات.
- السجلات المحفوظة تتوفر في الشاشة وفي ملف `bot.log` لمراجعة أي أخطاء وقت التشغيل.
